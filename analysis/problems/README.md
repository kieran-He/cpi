# 四个子题目分析

状态：Q1 `M1 已通过（能耗口径有条件）`；其余子题以各自文件和最新门禁回执为准。

| [Q1.md](Q1.md) | 单目的地往返运输能力与货箱分批 | A 建模；B 复核数据接口 | 题目附件、DEM、无人机参数 |

| [Q4.md](Q4.md) | 任务划分与独立资源配置 | A/B 共同 | 经验证且固定的 Q3 联合方案 |

## 数据继承关系

```text
原始题目/附件
      ↓
Q1：单航段物理计算、最大载荷、可行货箱批次
      ↓
Q2：运输路线、运输无人机、电池、时间窗和架次调度
      ↓
Q3：可重选运输路线/时刻，联合决定通信链路、中继位置和服务区间
      ↓
Q4：固定 Q3 方案下的 2 组/3 组划分、不可拆超节点和合计资源缺口
```

## 协作规则

- A 先冻结对应文件中的变量、约束、目标和验证口径，B 再实现代码。
- B 发现公式、单位或约束无法实现时，回到对应 Q 文件修订，不在代码中静默猜测。
- 每个 Q 文件的数值结果进入 `results/`，图表进入 `figures/`；结果不回写原始题目附件。
- 任一上游模型或参数变更时，必须重新检查所有下游文件的继承关系。
- Q1 已通过独立 M1 复验，能耗分项仍是须在结果中注明的有条件基线口径；其他子题的门禁状态以各自文件和最新回执为准。
