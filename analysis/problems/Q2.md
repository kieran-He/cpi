# Q2：异构无人机多目的地、多架次运输调度

状态：`M1、候选池/物理实现 P1 通过；ALNS 全量实验完成；P2 独立复核 PASS`。Q2 全量方案采用 ALNS 与时限导向路线扩充、禁忌变邻域搜索，并以小规模精确 MILP 作实现对照。迟到优先基线为 39 架次、加权迟到 0；当前架次数优先推荐方案为 24 架次、加权迟到 215,397.29、完工时间 8,268.57 秒、能耗 71.47 kWh。两方案均通过硬时限、路线物理和资源冲突校验。结果仅对记录的有限候选路线池和题目当前参数有效，不构成原问题全局最优证明。正式推荐方案及复现材料见 `results/q2/`。

## 1. 任务、数据与结论

每个运输架次从 O01 出发，访问一个或多个服务区后返回 O01。联合决定货箱分配、访问顺序、运输机型、具体无人机、共享电池和准备开始时刻，并输出逐箱交接完成时刻、路线与资源时间轴。输入沿用 [Q1](Q1.md) 的航段几何、时间、能耗和安全余量口径；Q1 的单服务区可行批次只作路线种子，Q2 可重新分组货箱。

`Supply Demand and Delivery Deadlines.xlsx` 的 `Cargo Box List` 含 80 箱、15 个服务区、30 个初始配送箱；货箱 ID 唯一，质量、体积、初始配送标记、期望时间和优先级均非空。非初始配送箱的初始配送截止为空，建模时只在标记为初始配送时使用该字段。医疗物资必须满足期望送达时间；初始配送箱必须满足初始配送截止；其他货箱的期望时间用于迟到评价，不作为硬约束。两类硬截止若同时适用则同时检查。

运输机附件给出 U01–U08 共 8 架无人机，以及 A/B/C 型共享电池 6/4/4 个。附件说明库存总数包含初始装机电池；模型只使用这份总库存，不额外增加机载电池。每块电池初始 SOC 为 100%，只能分配给同型号无人机。同一型号的电池可由该型号任一无人机使用。结果对应模板 `Q2_Transport Sorties` 和 `Q2_Box Deliveries`。

## 2. 候选架次池

候选架次集合记为 $\mathcal P$。每个候选 $p$ 固定机型 $g_p$、货箱集合 $C_p$、逐站交付分配 $C_{p,k}$ 与服务区访问序列

\[
O01\to v_{p,1}\to\cdots\to v_{p,h_p}\to O01.
\]

每个停靠点至少交付一个货箱；同一服务区在一架次中允许重复访问，但只有在其货箱分到不同停靠点时才保留该重复停靠。每箱恰好属于一个架次停靠点，且该停靠点的服务区必须与货箱附件一致。这样不预先排除题面未禁止、且可能改变载荷曲线的拆分访问路线。一次停靠的基础交接时间计一次，每箱附加交接时间计一次；同一停靠内的箱序按 `Cargo Box List` 工作表行序固定。

候选池按以下确定性、有界过程生成并冻结：

1. 将 Q1 代表可行分批方案中的批次，以及每个货箱在 A/B/C 三种机型下直接重算得到的物理可行单箱批次，转为单服务区路线种子。代表方案种子保留其指定机型；单箱种子不受 Q1 支配筛选档案限制。种子物理参数、余量口径与 Q1 一致；当前附件下每机型种子数不超过 80 个单箱候选加 18 个代表批次，即最多 98 条，保留全部 Q1 物理复算记录。
2. 对种子逐步执行货箱插入/移出、跨候选迁移或交换、访问点插入/交换、两条货箱不相交路线的合并与访问序列拼接；允许同一服务区货箱分到不同停靠点。每次操作后检查载荷、体积、逐段能耗和返航余量，按机型、停靠序列和货箱—停靠分配规范化候选 ID。
3. 每机型保留上限 $K_g$ 和提案上限 $R_g=10K_g$ 作为实验参数；迟到优先基线取 $K_g=150$，架次数端点取 $K_g=400$。新增路线从三个确定性排序队列轮流选取，避免只保留一种目标方向：时效队列按“时刻 0 的路线加权迟到、返航时长、能耗、箱数降序、候选 ID”升序；节能队列按“能耗、时刻 0 的加权迟到、返航时长、箱数降序、候选 ID”升序；批次数队列按“箱数降序、时刻 0 的加权迟到、能耗、返航时长、候选 ID”升序。Q1 种子全部预先入池且入队；此后在三个队列间轮流取尚未扩展的候选作父路线，按固定邻域顺序逐条流式提出后继。每提出一条路线就计入 $R_g$，在物理筛查和去重之前计数；不缓存未处理的邻域。通过物理复算且 ID 未见过的路线进入三个等待队列；轮到该路线时才加入保留池并扩展其邻域。路线达到 $K_g$、提案数达到 $R_g$ 或队列穷尽时停止。硬截止在准备时刻为 0 时仍不可满足的路线可安全剔除，因为所有开始时刻非负且硬截止都是上界。
4. 邻域展开次序固定为：货箱表行序逐箱移出/插入、候选 ID 升序逐对迁移/交换、停靠序列位置升序插入/交换、候选 ID 升序逐对尝试不相交路线合并并按较小候选 ID 路线在前拼接；每种移动内的目标停靠位置按访问序升序。先由机型、服务区序列和货箱—停靠分配生成规范化候选 ID，再做物理复算与 ID 去重；通过复算且未见过的路线分别按三队列键插入各队列。这样任何轮次均有确定的生成、筛选和入队顺序。
5. Q1 代表批次与可行单箱批次种子保证每箱至少出现在一个候选中；冻结并记录种子版本、$K_g$、$R_g$、各排序队列、邻域提案数、操作轮次、候选清单和被剔除原因。候选池外路线不属于整数模型搜索范围，池内最优不称为原始问题的全局最优。

迟到优先基准池最多 450 条；最终扩展池为 2,628 条。每机型种子上限为 98，小于基础池的 $K_g$。若对照小规模精确 MILP，每机型资源数分别为 A 型 4 架无人机和 6 块电池、B/C 型各 2 架无人机和 4 块电池；全规模成对互斥行规模过大，因此全量实例改用第 5 节 ALNS，而不再运行完整析取 MILP。

最终架次数优先方案在 $K_g=400,R_g=4{,}000$ 的基础路线池上执行时限导向路线扩充，再以禁忌变邻域搜索探索移除/修复组合，扩充后的路线总数为 2,628。该有限路线池和启发式搜索是当前正式结果的边界；池外路线不在最优性结论范围内。

候选生成应保留每个货箱至少出现在一个候选中的覆盖检查。若候选池不能覆盖全部货箱，或模型在池内无可行排程，记录为候选池/硬约束下不可行，并扩展路线池或报告不可行原因；不得静默删箱或放宽硬截止。

## 3. 物理可行性和预计算量

对于候选 $p$ 的每个飞行航段 $(i,j)$，令 $q_{p,ij}$ 为该段起飞前尚未交付货箱质量之和；离开 O01 时载荷为 $\sum_{c\in C_p}m_c$，每次完成交接后扣除该停靠点货箱质量，最后返航段载荷为 0。所有航段沿用 Q1 统一函数，要求

\[
q_{p,ij}\le Q_{g_p},\qquad
\sum_{c\in C_p}v_c\le V_{g_p},\qquad
E_p=\sum_{(i,j)\in p}E_{g_p,ij}(q_{p,ij})\le(1-\rho_{g_p})E_{g_p}^{\mathrm{use}}.
\]

如用等效航程作独立筛查，另检查 $\sum_{(i,j)\in p}d_{ij}/L_{g_p}(q_{p,ij})\le1$，但它不能替代总能量及返航余量约束。$E_p$ 与各段时间均在调度优化前复算并固定；当前 Q1 能耗分项为条件性基线口径，若官方答疑或 Q1 物理口径修订，必须重算 Q2 候选池。

预先计算：

- $P_p=t_{g_p}^{\mathrm{prep}}+|C_p|t_{g_p}^{\mathrm{load}}$：从准备开始至起飞的准备和装载时长；
- $\tau_{p,c}$：从起飞至货箱 $c$ 完成交接的相对时间，含飞行和沿途服务时间；
- $\tau_p^{\mathrm{return}}$：从起飞至返回 O01 的相对时间，含全部交接服务；
- $\mathrm{SOC}^{\mathrm{return}}_p=1-E_p/E_{g_p}^{\mathrm{use}}$；
- $T_p^{\mathrm{chg}}=t_{g_p}^{\mathrm{full}} f(\mathrm{SOC}^{\mathrm{return}}_p)$：该电池返回后充至 100% 的时长，其中

\[
f(s)=\begin{cases}
0.65\dfrac{0.90-s}{0.90}+0.35,&0\le s<0.90,\\[4pt]
0.35\dfrac{1-s}{0.10},&0.90\le s\le1.
\end{cases}
\]

同一停靠点先计基础交接时间，再按固定箱序逐箱计入附加时间并确定各自的 $\tau_{p,c}$。多个停靠点按访问序累积。机型参数、准备/装载时间、交接时间和电池满充时长均直接读取运输机附件，不补造运输周转参数。

## 4. 精确基准模型（仅用于小规模交叉核对）

下面的析取 MILP 保留为小规模精确基准，用于和 ALNS 对照小子集的可行性、目标值及资源先后关系；全量 80 箱实例不再调用它。变量、物理量和硬约束定义也作为 ALNS 的一致性合同。

集合：候选架次 $p\in\mathcal P$；货箱 $c\in\mathcal C$；与 $g_p$ 兼容的无人机集合 $\mathcal U_{g_p}$；与 $g_p$ 兼容的电池集合 $\mathcal B_{g_p}$。

决策变量：

- $x_p\in\{0,1\}$：是否选择候选架次 $p$；
- $y_{pu}\in\{0,1\}$：是否将 $p$ 分配给无人机 $u$；
- $z_{pb}\in\{0,1\}$：是否将 $p$ 分配给电池 $b$；
- $s_p\ge0$：工作站开始准备架次 $p$ 的时刻；未选架次由联结约束强制 $s_p=0$，选中架次也允许从时刻 0 开始；
- $d_c\ge0$：货箱交接完成时刻；$\ell_c\ge0$：相对期望时间的迟到量；
- $T\ge0$：所有运输无人机完成最后架次并返回 O01 的时刻。

由于每个选中架次含至少一个货箱且 80 个货箱不可重复分配，选中架次数不超过 80。令 $D_{\max}=\max_{p\in\mathcal P}\{D_p^U,D_p^B,P_p+\tau_p^{\mathrm{return}}\}$，取有效任务时域 $H=80D_{\max}$、$M=H+D_{\max}$。$H$ 是该有限候选池下的保守排程上界：所有资源在时刻 0 可用，没有最早开工/释放时间，硬截止均为上界；因此各资源链可消除正空闲并左移，且至多含 80 个架次。资源不重叠约束使用此推导的大 $M$，不用任意经验常数。

### 4.1 覆盖、分配与交付时刻

\[
\sum_{p:c\in C_p}x_p=1\quad(\forall c),\qquad
\sum_{u\in\mathcal U_{g_p}}y_{pu}=x_p,\qquad
\sum_{b\in\mathcal B_{g_p}}z_{pb}=x_p\quad(\forall p),
\]

只建立兼容机型的 $y_{pu}$、$z_{pb}$ 变量。未选架次不占用准备时刻：$0\le s_p\le Hx_p$。每箱完成时刻由唯一覆盖关系线性表达：

\[
d_c=\sum_{p:c\in C_p}\left[s_p+(P_p+\tau_{p,c})x_p\right]\quad(\forall c).
\]

医疗箱的 $d_c\le D_c^{\mathrm{desired}}$；对 `Required in Initial Delivery = Yes` 的货箱施加 $d_c\le D_c^{\mathrm{initial}}$。迟到线性化为

\[
\ell_c\ge d_c-D_c^{\mathrm{desired}},\qquad \ell_c\ge0,\qquad
F_{\mathrm{late}}=\sum_c w_c\ell_c.
\]

期望时间字段对所有货箱用于计算 $F_{\mathrm{late}}$；只有题面规定的医疗与初始配送条件构成硬截止。

### 4.2 无人机与共享电池排程

无人机从准备开始即被占用，至返航并完成周转后释放：

\[
D_p^U=P_p+\tau_p^{\mathrm{return}}+t_{g_p}^{\mathrm{turn}},\qquad
t_{g_p}^{\mathrm{turn}}=0
\]

当运输附件未提供周转常数时取 0。电池从准备开始占用，返航后充电至 100% 才能重新使用；其不可用时长为

\[
D_p^B=P_p+\tau_p^{\mathrm{return}}+T_p^{\mathrm{chg}}.
\]

对任意可分配给同一无人机 $u$ 的、货箱集合互不相交的候选架次对 $p<q$，令 $a^U_{pqu}\in\{0,1\}$ 表示 $p$ 排在 $q$ 前；令 $a^B_{pqb}\in\{0,1\}$ 表示共用电池 $b$ 时 $p$ 排在 $q$ 前。只有这些可能同时被选中的架次对需要建立以下约束；若两条路线共享货箱，唯一覆盖等式已禁止它们同时入选，其资源先后约束是冗余的，因此省略。约束分别对所有共同兼容无人机/电池及其余架次对建立：

\[
\begin{aligned}
s_p+D_p^U&\le s_q+M(1-a^U_{pqu})+M(2-y_{pu}-y_{qu}),\\
s_q+D_q^U&\le s_p+Ma^U_{pqu}+M(2-y_{pu}-y_{qu}),\\
s_p+D_p^B&\le s_q+M(1-a^B_{pqb})+M(2-z_{pb}-z_{qb}),\\
s_q+D_q^B&\le s_p+Ma^B_{pqb}+M(2-z_{pb}-z_{qb}).
\end{aligned}
\]

若两架次同时分配给同一资源，两条约束择一生效，使半开区间 $[s_p,s_p+D_p^U)$ 与 $[s_q,s_q+D_q^U)$（电池情形同理）不重叠；若任一架次未分配给该资源，相应先后约束由 $M$ 松弛。无人机的架次区间含准备、装载、飞行、交接和周转；电池区间含准备、装载、飞行、交接和完整回充。不同电池可并行充电，题目未给充电桩数量上限，故不设充电桩容量约束。

同一无人机返航后可以更换另一块已满电的同型号电池。该规则由 $y$、$z$ 的独立分配及各自不重叠约束表达，不强制一架无人机固定使用同一块电池。

### 4.3 多目标指标

\[
F_{\mathrm{late}}=\sum_cw_c\ell_c,\qquad
F_{\mathrm{makespan}}=T,\qquad
F_{\mathrm{energy}}=\sum_pE_px_p,\qquad
F_{\mathrm{sortie}}=\sum_px_p.
\]

对每个被选择架次，约束 $T\ge s_p+P_p+\tau_p^{\mathrm{return}}-M(1-x_p)$；因此完工时间按题面定义计至最后一架运输无人机返航，不把周转或回充时间加入任务完工时刻。小规模精确对照可分别求四个单目标端点，并用端点派生的 $\varepsilon$ 约束采样核对多目标定义；该精确流程只服务于小实例，不用于 80 箱全量方案。

全量 ALNS 采用两类词典序评价：迟到优先基线按 $F_{\mathrm{late}}$、$F_{\mathrm{makespan}}$、$F_{\mathrm{energy}}$、$F_{\mathrm{sortie}}$ 排序；架次数端点按 $F_{\mathrm{sortie}}$、$F_{\mathrm{late}}$、$F_{\mathrm{makespan}}$、$F_{\mathrm{energy}}$ 排序。ALNS 保存并报告启发式搜索发现的非支配候选，不声称完整帕累托前沿或最优性界。当前推荐的架次数端点为 24 架次；所有指标相同时，按规范化的“候选 ID、无人机 ID、电池 ID、准备时刻”序列确定性打破并列。

## 5. 求解、输出与验证

### 全量 ALNS 求解步骤

1. 从原始附件读取货箱、无人机、电池及节点数据，验证 ID、单位、缺失值和总量；调用 Q1 物理函数生成单站种子。
2. 按第 2 节确定性邻域扩展候选架次，预计算分段载荷、飞行时间、能耗、箱件交接偏移、返航时间与充电时长，并保存候选池清单。
3. 以路线池为 ALNS 邻域：随机移除、按目标贡献移除、按服务区/时限关联移除；再对最受限货箱优先做贪婪插入，插入多货箱路线时必须覆盖的货箱均未分配。
4. 每次插入后对已选路线重新做截止时间优先的列表调度，同时分配兼容无人机和电池；无人机占用至返航，电池占用至充电完成。不能满足任何硬时限或资源区间冲突的候选状态直接拒绝。用多种优先队列顺序重排资源，并通过自适应破坏算子权重与退火接受规则继续搜索。
5. 保存可行非支配解集，最终按“加权迟到、完工时间、能耗、架次数”的既定顺序推荐；结论标为启发式解，不给出全局最优或 MILP gap 证明。完整实验总墙钟预算不超过五小时；记录随机种子、迭代数、终止原因、耗时和验收结果。
6. 将架次数优先推荐方案写入根目录提交工作簿，并输出架次、交付、资源、路线和及时性表；迟到优先基线独立归档。生成总体及 Q2 流程图、候选池/求解状态和复现清单。`scipy.optimize.milp` 不参与全规模时序排程；另用路线覆盖模型审计候选池架次数下界，不把该覆盖解冒充可行调度。

| 架次数优先推荐方案 | 2,628（扩展候选池） | 架次、迟到、完工、能耗 | 24 | 215,397.29 | 8,268.57 | 71.47 | PASS |

架次数优先方案降低架次、完工时间和能耗，但增加非硬时限期望时间迟到；所有医疗和初始配送硬时限仍通过。24 架次是当前候选路线池中验证通过的启发式方案，不是最优性证明。

路线覆盖模型给出的 18 架次是 $K_g=400$ 路线池的覆盖下界，而不是可执行架次数。该池中全部 28 个 18 路线覆盖均未通过 B 型双机的必要硬时限排程检验；另一项扩展池覆盖探测也排除了“至多 18 架次且 B 型紧急路线不超过 4 条”的组合。证据只适用于各自记录的候选池，不排除池外路线改变结论。诊断见 `results/q2/sortie_lower_bound.json` 与 `results/q2/alns_deadline_vns.json`，复算入口分别为 `python -m src.experiments.q2_sortie_lower_bound` 和 `python -m src.experiments.q2_deadline_vns`。

### 验证与失败条件

- **箱件覆盖**：每个附件货箱恰好出现一次，服务区、供给类型和模板 ID 一致；候选池覆盖率为 100%。
- **路线物理**：逐段载荷按实际交付更新、体积按起飞装载总量检查、逐段能耗复算、返航 SOC 不低于机型安全余量；同一站箱序和每次停靠基础交接时间正确。
- **硬截止**：所有医疗物资满足期望时间，所有初始配送箱满足初始配送截止；非医疗、非初始配送箱只计迟到，不误加硬截止。
- **资源排程**：无人机区间、电池使用与回充区间逐对无重叠；机型、电池兼容；初始电池数已包含装机库存；所有回充时间按附件两阶段函数计算。
- **模型对照**：取小规模货箱/服务区子集，枚举该子集全部可行候选架次，与整数规划精确解对照目标值、覆盖与资源顺序；全规模 ALNS 只报告可行性和已达到的启发式目标值。
- **小实例实现核对记录（2026-09-24）**：可复现输入、完整 14 变量/26 行约束、SciPy/HiGHS 调用及枚举代码见 [微型实例脚本](../validation/q2_miniature_milp.py)，本次求解输出见 [运行记录](../validation/q2_miniature_milp.log)。实例含 2 箱、3 条可行候选路线（两条单箱路线和一条合并路线）、1 架无人机、1 块兼容电池；期望送达时间为 3、硬截止为 12，无人机占用时长为 5/6/7、电池占用时长为 7/8/9，逐箱交付偏移分别为 3、4、3/5，单箱/合并路线能耗为 2/2/8。目标为能耗 + 0.01×架次数 + 0.001×(两箱交付时刻、迟到量与完工时刻之和)。枚举表比较合并路线（目标 8.027）、单箱路线 0 后 1（4.055）、单箱路线 1 后 0（4.057）；MILP 选中单箱路线 0 后 1，准备开始时刻为 0 与 7，交付时刻为 3 与 11，完工时刻为 13。求解状态 optimal，incumbent 与 dual bound 均为 4.055，gap 为 0。该记录只核对微型约束实现，不代表完整 80 箱实例已求解。
- **候选池敏感性**：本轮比较每机型 $K=100,150,225$ 的候选路线池（对应 $R=1{,}000,1{,}500,2{,}250$），分别报告 ALNS 可行方案的目标向量与结构；由于随机种子和池规模同步变化，该实验只作描述性敏感性检查，不用于单独归因池规模效应。各池版本、生成操作、候选数与求解状态记录在 `results/q2/alns_sensitivity.json`。
- **停止/失败条件**：候选池覆盖不足或 ALNS 未找到完整可行排程时不生成完整方案；物理复算与方案不一致时回退物理预计算；资源冲突或硬截止违规时判定结果未通过验证。ALNS 结果只标为启发式可行解，不报告其不存在的 MILP 最优性界。

推荐方案的架次、交付、资源、路线、及时性表和提交工作簿均位于 `results/q2/` 根目录；迟到优先基线归档于 `results/q2/baseline_lateness/`。求解记录见 `results/q2/alns_sortie_k400_seed20260929.json`。Q2 的已验证方案作为 Q3 基线或初始解；Q3 可为满足连续通信约束重新生成路线并优化运输决策。

## 6. 假设与边界

| 级别 | 假设/约定 | 依据与复验 |
|---|---|---|
| 关键 | Q1 的航段时间、能耗和返航安全余量规则作为 Q2 物理核算接口 | 题面附录 2；Q1 能耗分项仍是有条件的基线口径，口径改变须重算 Q2 |
| 可放宽 | 模板 `Start Time (s)` 解释为开始准备时刻，准备与装载占用无人机及所分配电池 | 题面给出准备、装载和架次开始字段但未明确字段时点；以起飞时刻 $s_p+P_p$ 换算，并对准备/装载资源占用口径做敏感性复核 |
| 可放宽 | 无人机周转时间未在运输附件给出，故取 0；电池回充与返航后周转可以并行 | 运输附件没有运输机周转常数；若后续答疑补充参数，加入 $t_g^{\mathrm{turn}}$ 并重算 |
| 可放宽 | 充电桩数量不构成瓶颈，不同电池可并行充电 | 题面附录 2 允许不同能量资源并行充电且附件未给充电桩数量 |
| 范围限制 | 候选池通过已记录的有限邻域生成，不包含全部理论可行路线 | 为避免把路线池限制伪装成原问题全局最优；通过扩展邻域敏感性比较其影响 |
